# Конспектор

## О проекте

> ИИ-помощник, который отвечает на вопросы по вашим конспектам и лекциям — и всегда показывает, откуда взял ответ.

**Конспектор** - небольшой сервис для студентов. Преподаватель загружает учебные материалы (лекции, конспекты, методички), а студент задаёт вопрос обычным языком и получает краткий ответ, построенный *только* на этих материалах, со ссылками на источники. Если в материалах нужной информации нет, сервис честно сообщает об этом, а не выдумывает ответ.

С точки зрения ИИ проект построен по схеме RAG (Retrieval-Augmented Generation): материалы разбиваются на фрагменты, которые модель эмбеддингов превращает в векторы; по вопросу находятся наиболее похожие фрагменты, а языковая модель (LLM) формулирует ответ только на их основе.

Основные пользователи:

- студент;
- преподаватель.

Основные функции:

- загрузка учебных материалов;
- вопрос по материалам и получение ответа;
- просмотр источников ответа.

## Комплект документации

Для проекта потребуется следующий набор технической документации:

1. **Описание проекта** - для всех участников и новых читателей; даёт общее представление о цели, пользователях и функциях сервиса.
2. **Требования** - для аналитиков, разработчиков и тестировщиков; фиксируют, что должна делать система и как проверить результат.
3. **Диаграммы и архитектура системы** - для разработчиков и архитекторов; показывают компоненты системы и их взаимодействие.
4. **Документация API** - для разработчиков, которые подключают интерфейс или сторонние сервисы; описывает запросы, ответы и коды ошибок.
5. **Документация ML-модели** - для ML-инженеров и проверяющих; описывает используемые модели, параметры поиска, метрики качества и ограничения.
6. **Руководство пользователя** - для студентов и преподавателей; объясняет, как загружать материалы и задавать вопросы.
7. **Руководство по развёртыванию и эксплуатации** - для администраторов; описывает установку, настройку и обслуживание сервиса.

Сейчас подготовлены документы 1–3, остальные будут добавлены по мере развития проекта.
