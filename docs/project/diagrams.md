# Диаграммы

## Диаграмма последовательности

Диаграмма показывает выполнение сценария [UC-01. Ответ на вопрос по материалам](requirements.md): от вопроса студента до ответа с источниками, включая оба альтернативных сценария.

```mermaid
sequenceDiagram
    autonumber
    actor Student as Студент
    participant System as Система
    participant Embedder as Модель эмбеддингов
    participant Index as Векторный индекс
    participant LLM as Языковая модель

    Student->>System: Задать вопрос
    System->>Embedder: Передать текст вопроса
    Embedder-->>System: Вернуть вектор вопроса
    System->>Index: Найти похожие фрагменты
    Note right of Index: три фрагмента с наибольшим сходством
    Index-->>System: Вернуть фрагменты и оценки сходства

    alt Подходящие фрагменты найдены
        System->>LLM: Передать вопрос и фрагменты
        alt Модель ответила вовремя
            LLM-->>System: Вернуть ответ
            System-->>Student: Показать ответ и источники
        else Ошибка или превышено время ожидания
            System-->>Student: Сообщить об ошибке и предложить повторить позже
        end
    else Фрагменты не найдены
        System-->>Student: Сообщить, что в материалах ответа нет
    end
```

Участники диаграммы:

| Участник | Роль |
|---|---|
| Студент | пользователь, задающий вопрос |
| Система | серверная часть: принимает вопрос, координирует работу остальных компонентов |
| Модель эмбеддингов | ML-компонент: превращает текст вопроса в вектор |
| Векторный индекс | хранилище векторов фрагментов материалов, поиск по сходству |
| Языковая модель | ML-компонент: формирует ответ по вопросу и найденным фрагментам |

## Диаграмма классов

Диаграмма описывает основные сущности сервиса и связи между ними.

```mermaid
classDiagram
    class User {
        +int id
        +string name
        +string role
    }
    class Document {
        +int id
        +string title
        +string format
        +string status
    }
    class Chunk {
        +int id
        +string text
        +int page
    }
    class Question {
        +int id
        +string text
        +datetime askedAt
    }
    class Answer {
        +int id
        +string text
        +float topSimilarity
    }

    User "1" --> "*" Document : загружает
    User "1" --> "*" Question : задаёт
    Document "1" --> "*" Chunk : состоит из
    Question "1" --> "1" Answer : получает
    Answer "*" --> "1..*" Chunk : опирается на
```

Сущности:

| Класс | Назначение |
|---|---|
| `User` | пользователь системы; поле `role` принимает значения «студент» или «преподаватель» |
| `Document` | загруженный учебный материал; `status` показывает, проиндексирован ли он |
| `Chunk` | фрагмент материала, по которому ведётся поиск и на который ссылается ответ |
| `Question` | вопрос студента |
| `Answer` | ответ языковой модели; `topSimilarity` — сходство лучшего найденного фрагмента с вопросом |
